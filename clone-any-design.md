# Clone Any Design

## Overview

This skill enables you to recreate any app screen design with pixel-perfect accuracy from a screenshot.

## Capabilities

- Extract exact colors, fonts, and spacing from screenshots
- Replicate UI components with precise measurements
- Match typography including font weights and sizes
- Recreate complex layouts and interactions
- Build responsive, self-contained screens

## Usage

When a user provides a screenshot of an app screen:

1. **Analyze the design** - Examine colors, typography, layout, and components
2. **Extract specifications** - Identify exact measurements, colors, fonts, and spacing
3. **Recreate the design** - Build the screen with pixel-perfect accuracy
4. **Add interactions** - Implement proper states and behaviors

## Design Replication Rules

### Visual Accuracy

- Match every color exactly - extract hex codes from the image
- Match font sizes, weights, and spacing precisely
- Match border radius on all elements
- Match padding and margin on every element
- Match layout structure exactly (columns, rows, grids)
- Match shadows, gradients, and backgrounds
- Match icon sizes and placements

### Typography Rules

- Identify font family (Sans-serif, Serif, Monospace)
- Match heading, body, and caption sizes
- Match letter spacing and line height
- Match font weights (bold, medium, regular)

### Component Rules

- Every button must match size, color, radius, label, and shadow
- Every card must match padding, background, border, and shadow
- Every input field must match border, placeholder style, and height
- Every list item must match spacing, icon placement, and dividers
- Every modal or bottom sheet must match handle, background, and padding

### Interaction Rules

- Add pressed state styling to all buttons
- Add scroll behavior where content overflows
- Make layout responsive to different screen heights

## Output Requirements

- Build complete, self-contained screens
- Use no placeholder text unless shown in screenshot
- Do not add elements not in the screenshot
- Do not remove elements from the screenshot
- Final output must look identical to the screenshot when rendered
